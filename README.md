# 📊 Frontend - Sistema de Seguimiento Estudiantil 

Este proyecto corresponde al **frontend** del sistema de seguimiento estudiantil con **Inteligencia Artificial**, desarrollado como parte de un proyecto académico.  
Está construido con **React** y desplegado en **Vercel**.

---

## 🛠️ Tecnologías principales

- [React](https://react.dev/) - Librería para la construcción de interfaces de usuario.  
- [TailwindCSS](https://tailwindcss.com/) - Estilos y componentes UI.   

---

## 📋 Requisitos previos

- [Node.js](https://nodejs.org/) **v22.11.0 o superior**  
- [NPM](https://www.npmjs.com/)  instalado  
- [Vercel](https://vercel.com/) (opcional para despliegue)  

---

## ⚙️ Instalación en local

```bash
# Clonar el repositorio
git clone https://github.com/mberrios05/tesis/tree/main/tesis)
cd tesis

# Instalar dependencias
npm install

# Ejecutar en modo desarrollo
npm run dev
